# Corso JPA

Progetto di esempio per l'utilizzo di Jakarta Persistence API (JPA) con Hibernate e MySQL.

## Tecnologie utilizzate
- Java 21
- Maven
- Hibernate 6.6
- MySQL 9.1
- JPA 3.1
- Visual Studio Code

## Avvio rapido

1. Clona il repository
2. Configura `persistence.xml`
3. Avvia l'applicazione
